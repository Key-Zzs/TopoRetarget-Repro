# Geometry-Aware Physics Retargeting

Geometry-aware Stage16D optimization is gated by stable free-object
calibration. Exact `RuntimeCollisionProxyPenetrationV1` remains the formal
metric; any online signal is only a bounded candidate-ranking aid and must be
qualified against exact top-K audits before use. Source and corrected paths
must use the same exact shapes, transforms, pair filters, and aggregation.

D.4R3 stopped at
`STAGE16D_STABLE_FREE_OBJECT_GRASP_CALIBRATION_BLOCKED`: the frozen C1/C2
development matrix had zero eligible candidates. Therefore no dynamic
reference, V2 contract, online-signal qualification, G1/G2 optimization,
trajectory requalification, demonstration, BC, PPO, two-clip PPO, or V2 export
was authorized. The 10 mm maximum and 3 mm contact-active-p95 absolute gates
remain unchanged.

Runtime collision proxies are not visual truth. Factor-8 changes time
semantics; the explicit 3P+3R wrist is not a real robot arm; object physics is
engineering-nominal and uncalibrated; no real-dynamics or sim-to-real claim is
made.
