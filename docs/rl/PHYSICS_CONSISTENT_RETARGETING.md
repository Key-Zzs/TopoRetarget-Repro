# Physics-Consistent Retargeting Contract

`physics_consistent_retargeting_v1` is an engineering extension of the Stage
16 world-wrist task. It preserves source robot intent and contact semantics but
replaces strict source-object tracking with a soft prior. The object trajectory
is generated by a free, zero-gravity, unsupported PhysX rigid body.

## Runtime contract

- Simulation/control: 120/20 Hz, decimation 6, 321 control steps.
- Reference: immutable 41 source keys expanded by the already authorized
  shared factor-8 view.
- Action: three wrist translations, three wrist SO(3) residuals, then 20
  canonical finger residuals; dimension 26 and bounds `[-1, 1]`.
- Observation: the frozen 764-D Stage 16-C contract.
- Actuation: explicit virtual 3P+3R joints plus 20 finger joints.
- Object: not an action, decision variable, attachment, or state-write target.
- Forbidden: wrist/object rollout writes, hidden force, teleport, attachment,
  task-specific controller parameters, and strict object-path termination.

The 1/128/4096 environment smokes passed on real CUDA PhysX. The 4096-env
selection completed in 34.64 seconds with finite `[4096, 764]` observations
and zero formal wrist/object rollout writes.

## Semantic and topology contract

The shared body groups are thumb, index, middle, ring, pinky, and palm.
Coverage, onset order, duration, persistence, terminal coverage, and forbidden
contacts are evaluated independently. Very short transient, ghost,
self-contact, inactive-object, and source deep-penetration single-frame events
are excluded by the frozen topology extractor.

Both current clip classifications are partial because the source C3 contact
telemetry is sparse. The generic fallback describes the evidence; it does not
create clip-conditioned reward or control behavior.

## Reward and success

The shared pre-search `semantic_balanced_v1` reward uses wrist 1.5, fingers
1.0, links 1.0, contact coverage 3.0, persistence 2.0, onset 0.5, final
topology 2.0, forbidden contact -2.0, penetration -4.0, impulse outlier -1.0,
object stability -0.25, action/first/second difference -0.01/-0.02/-0.01,
semantic progress 4.0, relative-pose progress 1.0, source-object soft prior
0.10, terminal success 10.0, and catastrophic failure -10.0.

Success additionally requires finite state, action bounds, wrist/finger and
workspace safety, complete 321-step evidence, semantic reach, persistent
contact topology, causal contact-to-motion evidence, terminal stability, no
hidden control/state writes, and an independent penetration audit. No reward
sum alone can pass a trajectory.

## Optimizer and geometry boundary

The selected phase-wise spline CEM uses 16 knots, population 64, four robust
replicas, five iterations, and 12 elites for both clips. Candidates are ranked
lexically by failure classes before fidelity, smoothness, effort, and stable
candidate ID. The free object rollout is never optimized directly.

The current audit transforms 21 runtime hand collision proxies against the
object convex hull over all 321 steps and 20 replicas. It measures a
penetration lower bound and supporting-plane gap. It cannot prove the frozen
upper-bound gate or the required no-more-than-10-percent source degradation.
The visual meshes are non-watertight and the Stage 12 SDF is not
metric-compatible. The correct result is therefore a formal blocker, not a
numerical pass.

## Artifact contract

`PhysicsConsistentRetargetedTrajectoryV1` contains NPZ and Zarr trajectories,
manifest and quality JSON, Parquet contacts, the 321x26 action trace, and a
source/corrected comparison CSV. Its manifest binds source, action,
qualification, geometry hashes, factor-8 mapping, no-hidden-control counters,
and the free-object provenance. Current packages are explicitly partial.

`PhysicsQualifiedIsaacTrajectoryV2` requires a passing formal geometry gate
