# Generic target-hand contract

The target-hand boundary is data-driven. A target hand is selected by `robot_id` through
`RobotHandRegistry`; no retargeting or optimization path may special-case a robot identity.

## Contract objects

- `RobotHandSpec`: stable identity, side, asset bundle, semantic layout, expected topology, and
  provenance.
- `RobotHandAssetBundle`: repository-relative URDF/MJCF paths and upstream provenance.
- `RobotKinematicSpec`: root link, explicit actuated joint order, neutral q, and declared limits.
- `RobotSemanticAnchorProfile`: semantic layout/profile identity and assumptions.
- `RobotSurfaceProfile`: visual and surface-contact declarations.
- `RobotCollisionProfile`: collision geometry and self-collision declarations.
- `RobotSimulationSpec`: optional MJCF and simulator joint mapping metadata.
- `RobotHandModel`: the loaded URDF/FK/anchor/geometry implementation.
- `RobotHandRegistry`: YAML discovery, asset resolution, validation, and model construction.

The public `load_artimano_model("right"|"left"|"rh"|"lh")` API remains available, but it is a
compatibility wrapper that delegates to the registry.

## Required invariants

Each registered hand must declare its own root link, DoF count/order, neutral q, limits, semantic
anchor profile, visual/collision policy, optional simulation asset, and source hashes. The parser's
XML order is never the public qpos order. A hand may have any DoF count and need not use `palm` as
its root or have Arti-MANO's collision coverage.

Anchor count and Jacobian shapes are derived from the selected profile. The current Arti-MANO
instance uses 21 MediaPipe-compatible anchors and 22 actuated joints, but those values are not
contract-wide constants.

## Arti-MANO instance

`configs/robots/artimano_rh.yaml` and `artimano_lh.yaml` register independent URDFs. Both use the
tracked `third_party/robot_hands/artimano` bundle, root `palm`, explicit 22-name qpos order, all-zero
neutral q, the versioned `artimano_mediapipe21` anchor profile, and separate visual/collision
geometry. The right and left URDFs are parsed independently; LH is not generated by mirroring RH.

F0 stops at shared infrastructure. It does not add Wuji Hand2, a penetration loss, solver-profile
changes, or new Stage 10 artifacts.
