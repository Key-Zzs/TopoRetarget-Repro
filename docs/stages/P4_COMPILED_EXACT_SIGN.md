# P4 Certified Compiled Exact Sign

P4 is an engineering performance experiment, not a paper-method claim.  It
extends P3's compiled closest-point kernel with exact float64 generalized
winding, strict near-threshold fallback, and a 1-Lipschitz certified reuse
rule for six spatial-FD probes.  It does not modify a running Stage-12 job or
its artifacts, and it is not selected as a default backend without the stated
qualification evidence.
